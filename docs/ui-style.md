# UI Style — Izzy Store

## Paleta
- Fundo base: `#f6f0e9`
- Superfície/cartões: `#fffaf3`
- Texto principal: `#2f2a28`
- Texto secundário: `#6f655f`
- Acento: `#d4a373`
- Acento forte: `#c08b58`
- Acento escuro: `#b6804f`
- Sombra suave: `0 12px 30px rgba(47,42,40,0.08)`

## Tipografia
- Corpo: DM Sans (400/500/600/700)
- Títulos: Playfair Display (600/700)

## Componentes
- Navbar em vidro bege com logo "IS" degradê.
- Botões primários com gradiente acento, bordas arredondadas 12px, sombra suave.
- Cards de produto com pill de categoria, hover leve (translateY -6px).
- Skeleton loaders em grid para carregamento de produtos.
- Formulários com rótulo flutuante, borda inferior neutra e realce em acento.

## Layout
- Seções com respiro amplo (2–4rem) e grid fluido.
- Hero dividido (texto + arte geométrica), CTA banner em gradiente bege.
- Carrinho/checkout sobre cartões claros com borda `#e8ddc9`.
